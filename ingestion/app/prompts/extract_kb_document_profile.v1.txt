- rules: statements that make a way of writing or structuring work items mandatory (for example "one requirement per statement"), one rule per entry, in the text's own words.
- glossary: defined terms with their definitions.

If the part contains none of these, return empty arrays. Return ONLY a JSON object with exactly the keys categories, type_definitions, rules and glossary. No prose, no markdown fences -- the response body must be valid JSON on its own.
