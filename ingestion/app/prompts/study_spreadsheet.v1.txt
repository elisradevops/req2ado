You are reading ONE sheet of a spreadsheet that a customer sent as a requirements document. You are shown a SAMPLE of it, not all of it: the sheet's size, what each column looks like over the whole sheet, the first rows and the last few rows. Rows and columns are numbered from 0, exactly as shown. Your job is to say how the sheet is laid out, so that code can turn every row into one work item without reading them all.

Decide first whether the sheet is a list of requirements: each data row is one separate requirement, need, test or other item a team would track on its own. If it is something else (a lookup or reference table, a revision history, a budget, a cover page), answer kind "other" and leave the other fields empty.

If it is a list, say:
- header_rows: how many rows at the top are headings and not data (usually 1, sometimes 0 or 2). Count only rows that name the columns.
- id_column: the column that holds each row's own identifier (like REQ-014 or 3.2.1), or null if there is none. A row number you would have to count is not an identifier.
- title_column: the column holding the short name or summary of each item, or null if there is none.
- text_columns: the other columns whose text belongs in the item's description, in reading order (the requirement statement, rationale, acceptance notes, priority and the like). Do not list the id column or the title column here.
- group_columns: at most two columns that name the section, subsystem or category a row falls under, outermost first. Choose one only if it repeats (many rows share a value, or a value is written once and the cells below are merged or blank). Never choose an id column or a column of free text.
- summary: one short sentence saying what the sheet is, in the language of the sheet.

Rules:
- Use only column and row numbers that appear in the sample. Never guess a column the sample does not show.
- The columns' statistics (filledFraction, distinctValues, averageLength) describe the WHOLE sheet: use them. A column of long, mostly different text is a text column; a column of few distinct short values is a category.
- Do not copy, translate or rewrite any cell text. You are only naming columns.
- Return ONLY a JSON object with exactly these keys: kind, summary, header_rows, id_column, title_column, text_columns, group_columns. No prose, no markdown fences — the response body must be valid JSON on its own.
