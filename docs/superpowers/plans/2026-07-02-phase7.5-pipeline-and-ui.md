# Phase 7.5 Pipeline Driver + Minimal UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the biggest gap found in this planning pass — no phase 0-7 actually chains the built pieces (ingestion, leveling, distillation, fidelity, dedup, MCP write-back) into one working pipeline, and the frontend has only a login page. This phase builds a real, working BASELINE-mode job: upload a document → ingest → level → distill → dry-run preview → confirm → write to ADO (mock backend) idempotently. **Without this phase, Phases 0-7 are seven disconnected, individually-tested libraries, not a working product** — this was confirmed with the user as the highest-priority gap before Phase 8 (which assumes a pipeline exists to harden and E2E-test).

**Architecture:** Extends the existing (Phase 0, unused-until-now) `Job`/`AuditEntry` Prisma models and BullMQ dependency. `IngestionHttpClient` (orchestrator → Python `/ingest` and `/level`, plain `axios`, no MCP involved — this is a direct service-to-service HTTP call, distinct from the MCP protocol used for ADO writes) and `McpClient` (orchestrator → `mcp-ado-server`, using the real `@modelcontextprotocol/sdk` `Client` + `StreamableHTTPClientTransport`, not a hand-rolled HTTP call — this is the first REAL MCP client in the whole project; every prior phase only built the MCP *server* side) are new orchestrator services. `PipelineWorker` (a BullMQ worker, run as a separate Node process) is the actual glue: pulls a job off the queue, calls ingestion, builds the dry-run diff (Phase 7's `DryRunService`), and — only on explicit confirm — calls `McpClient` to create/link work items and records each in `IdempotencyService`. **Scope is BASELINE mode only** — SURVEY-mode pipeline wiring (which generative step runs when, per-node vs per-tree dedup timing) was explicitly deferred as an unresolved design question in both Phase 5's and Phase 6's Self-Review Notes; this phase does not resolve that, it only unblocks BASELINE, which needs no such design questions answered (no LLM, no dedup ambiguity — Phase 4's `customer_id` and `fidelity_hash` are already fully specified). The frontend gains an `Upload` page (file picker, mode fixed to "Baseline" for now with a disabled "Survey (coming soon)" option, submit) and a `JobStatus` page (poll job status, render the dry-run diff table, a confirm-write button).

**Tech Stack:** Orchestrator: `bullmq`/`ioredis` (already listed dependencies, unused until now), `@modelcontextprotocol/sdk`'s client APIs (already listed, only the server-side APIs used until now), `multer` (**new dependency** — NestJS's standard file-upload middleware, needed for the `POST /jobs` multipart endpoint; not previously needed since no endpoint accepted file uploads). Frontend: no new dependencies (MUI/axios/MobX already present).

## Global Constraints

- BASELINE mode only. Do not attempt to wire SURVEY-mode's LLM leveling/distillation/dedup into this pipeline — that integration point is explicitly unresolved (see Phase 5/6 Self-Review Notes) and out of scope here. The frontend's "Survey" mode option is visibly present but disabled, not hidden — so the gap is visible to the user, not silently absent.
- The pipeline calls the Python ingestion service's REAL `/ingest` and `/level` endpoints (Phase 1/4, already built and tested) — it does not reimplement any parsing/leveling logic.
- ADO writes in this phase go through `mcp-ado-server`'s REAL MCP protocol (the actual `@modelcontextprotocol/sdk` `Client`, talking Streamable HTTP JSON-RPC) — never a raw `fetch`/`axios` call to `mcp-ado-server`'s `/mcp` endpoint. This is the first phase where the MCP client side is exercised at all.
- `dry_run: true` is the default per `config.yaml` — a job's first pass ALWAYS produces a diff without writing. A second, explicit "confirm" step is required before any real (or mock) ADO write happens. This mirrors Phase 7's `DryRunService`, now actually invoked by real job flow instead of only unit-tested in isolation.
- Every ADO write goes through `IdempotencyService.lookup()` before writing and `IdempotencyService.record()` after — re-running or re-confirming the same job must not create duplicate work items, extending Phase 7 Task 10's proven contract into the real pipeline.
- Do not modify any Phase 1-7 production code's public interface — this phase is purely additive orchestration calling already-built, already-tested functions/classes by their existing signatures.
- Type hints/explicit types on every function signature; existing repo test conventions per package (Jest for orchestrator, Vitest for frontend).

```typescript
// orchestrator/src/modules/pipeline/ingestion-http.client.ts
import { Injectable } from '@nestjs/common';

/**
 * Calls the Python ingestion service's real /ingest and /level endpoints
 * (Phase 1/4, already built and tested) directly over HTTP — plain
 * service-to-service calls, NOT the MCP protocol (which is reserved for
 * ADO writes via mcp-ado-server, see McpClient). CanonicalDoc/WorkItemTree
 * are passed through as loosely-typed JSON on the TS side — the
 * orchestrator's job here is orchestration, not re-validating Python's own
 * pydantic-enforced shapes.
 */
@Injectable()
export class IngestionHttpClient {
  constructor(private readonly baseUrl: string) {}

  async ingest(fileBuffer: Buffer, filename: string): Promise<Record<string, unknown>> {
    const form = new FormData();
    form.append('file', new Blob([fileBuffer]), filename);
    const response = await fetch(`${this.baseUrl}/ingest`, { method: 'POST', body: form });
    if (!response.ok) {
      throw new Error(`Ingestion /ingest request failed: ${response.status}`);
    }
    return response.json();
  }

  async level(doc: Record<string, unknown>, customerId: string | null): Promise<Record<string, unknown>> {
    const url = customerId
      ? `${this.baseUrl}/level?customer_id=${encodeURIComponent(customerId)}`
      : `${this.baseUrl}/level`;
    const response = await fetch(url, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(doc),
    });
    if (!response.ok) {
      throw new Error(`Ingestion /level request failed: ${response.status}`);
    }
    return response.json();
  }
}
```

```typescript
// orchestrator/src/modules/pipeline/mcp.client.ts
import { Injectable } from '@nestjs/common';
import { Client } from '@modelcontextprotocol/sdk/client/index.js';
import { StreamableHTTPClientTransport } from '@modelcontextprotocol/sdk/client/streamableHttp.js';

/**
 * Real MCP protocol client for mcp-ado-server — the first place in this
 * project that uses the SDK's CLIENT-side APIs (every prior phase only
 * built the SERVER side, inside mcp-ado-server itself). Connects and
 * closes per call, matching mcp-ado-server's own stateless-per-request
 * server design (see mcp-ado-server/src/server.ts's comment on why a
 * StreamableHTTPServerTransport in stateless mode is single-use).
 */
@Injectable()
export class McpClient {
  constructor(
    private readonly mcpUrl: string,
    private readonly bearerToken: string,
  ) {}

  private async withClient<T>(fn: (client: Client) => Promise<T>): Promise<T> {
    const client = new Client({ name: 'req2ado-orchestrator', version: '0.1.0' });
    const transport = new StreamableHTTPClientTransport(new URL(this.mcpUrl), {
      requestInit: { headers: { Authorization: `Bearer ${this.bearerToken}` } },
    });
    await client.connect(transport);
    try {
      return await fn(client);
    } finally {
      await client.close();
    }
  }

  private parseToolTextResult<T>(result: { content: { type: string; text?: string }[] }): T {
    const textContent = result.content.find((item) => item.type === 'text');
    return JSON.parse(textContent?.text ?? 'null') as T;
  }

  async createWorkItem(type: string, fields: Record<string, string>): Promise<{ id: number }> {
    return this.withClient(async (client) => {
      const result = await client.callTool({ name: 'ado_create_work_item', arguments: { type, fields } });
      return this.parseToolTextResult(result as any);
    });
  }

  async linkParentChild(childId: number, parentId: number): Promise<void> {
    await this.withClient(async (client) => {
      await client.callTool({ name: 'ado_link_parent_child', arguments: { childId, parentId } });
    });
  }

  async discoverFields(workItemType: string): Promise<string[]> {
    return this.withClient(async (client) => {
      const result = await client.callTool({ name: 'ado_discover_fields', arguments: { workItemType } });
      return this.parseToolTextResult(result as any);
    });
  }
}
```

```typescript
// orchestrator/src/modules/pipeline/pipeline.worker.ts
import type { PrismaClient } from '@prisma/client';
import type { IngestionHttpClient } from './ingestion-http.client';
import type { DryRunService, DryRunTreeNode } from '../writeback/dry-run.service';
import type { IdempotencyService } from '../writeback/idempotency.service';

export interface PipelineJobInput {
  id: string;
  areaPath: string;
  customerId: string | null;
  fileBuffer: Buffer;
  filename: string;
}

export interface PipelineWorkerDeps {
  ingestionClient: IngestionHttpClient;
  dryRunService: DryRunService;
  idempotencyService: IdempotencyService;
  prisma: PrismaClient;
}

interface LeveledNode {
  local_id: string;
  fidelity_hash: string;
  customer_id: string | null;
}

/**
 * The actual pipeline glue that Phases 1-7 never built: chains the real
 * ingestion service (/ingest -> /level, Phase 1/4) into Phase 7's
 * DryRunService, persisting progress on the Job row (Phase 0's model,
 * unused until this task). BASELINE mode only — see this plan's header for
 * why SURVEY-mode wiring is explicitly out of scope here.
 */
export async function runPipelineJob(
  job: PipelineJobInput,
  deps: PipelineWorkerDeps,
): Promise<ReturnType<DryRunService['diff']> extends Promise<infer T> ? T : never> {
  try {
    const doc = await deps.ingestionClient.ingest(job.fileBuffer, job.filename);
    const tree = (await deps.ingestionClient.level(doc, job.customerId)) as { nodes: LeveledNode[] };

    const diffInputs: DryRunTreeNode[] = tree.nodes.map((node) => ({
      localId: node.local_id,
      sourceHash: node.fidelity_hash,
      customerId: node.customer_id,
      areaPath: job.areaPath,
    }));

    const diff = await deps.dryRunService.diff(diffInputs, deps.idempotencyService);

    await deps.prisma.job.update({ where: { id: job.id }, data: { status: 'diff_ready', dryRunDiff: diff } });
    return diff;
  } catch (error) {
    await deps.prisma.job.update({ where: { id: job.id }, data: { status: 'failed' } });
    throw error;
  }
}
```

```typescript
// orchestrator/src/modules/pipeline/jobs.service.ts
import { Injectable } from '@nestjs/common';
import type { PrismaClient } from '@prisma/client';
import { Queue } from 'bullmq';
import type { McpClient } from './mcp.client';
import type { IdempotencyService } from '../writeback/idempotency.service';

export interface SubmitJobInput {
  userId: string;
  areaPath: string;
  customerId: string | null;
  fileBuffer: Buffer;
  filename: string;
  sourceHash: string;
}

@Injectable()
export class JobsService {
  private readonly queue: Queue;

  constructor(
    private readonly prisma: PrismaClient,
    private readonly mcpClient: McpClient,
    private readonly idempotencyService: IdempotencyService,
    redisUrl: string,
  ) {
    this.queue = new Queue('req2ado-pipeline', { connection: { url: redisUrl } as any });
  }

  async submit(input: SubmitJobInput): Promise<{ jobId: string }> {
    const job = await this.prisma.job.create({
      data: {
        userId: input.userId,
        mode: 'baseline',
        status: 'pending',
        sourceHash: input.sourceHash,
        areaPath: input.areaPath,
        customerId: input.customerId,
        originalFilename: input.filename,
      },
    });
    await this.queue.add('ingest-and-level', {
      id: job.id,
      areaPath: input.areaPath,
      customerId: input.customerId,
      fileBuffer: input.fileBuffer,
      filename: input.filename,
    });
    return { jobId: job.id };
  }

  async getById(id: string): Promise<{ id: string; status: string; dryRunDiff: unknown } | null> {
    const job = await this.prisma.job.findUnique({ where: { id } });
    if (!job) return null;
    return { id: job.id, status: job.status, dryRunDiff: job.dryRunDiff };
  }

  async confirm(id: string): Promise<{ status: string; createdCount: number }> {
    const job = await this.prisma.job.findUnique({ where: { id } });
    if (!job || job.status !== 'diff_ready') {
      throw new Error(`Job ${id} is not in a confirmable state`);
    }
    await this.prisma.job.update({ where: { id }, data: { status: 'writing' } });

    const diff = job.dryRunDiff as { localId: string; action: string }[];
    let createdCount = 0;
    for (const entry of diff) {
      if (entry.action === 'create') {
        const created = await this.mcpClient.createWorkItem('Requirement', {});
        await this.idempotencyService.record(job.sourceHash, job.customerId, job.areaPath, created.id);
        createdCount += 1;
      }
    }

    await this.prisma.job.update({
      where: { id },
      data: { status: 'succeeded', confirmedAt: new Date(), completedAt: new Date() },
    });
    return { status: 'succeeded', createdCount };
  }
}
```

```typescript
// orchestrator/src/modules/pipeline/jobs.controller.ts
import { BadRequestException, Controller, Get, NotFoundException, Param, Post, UploadedFile, UseInterceptors } from '@nestjs/common';
import { FileInterceptor } from '@nestjs/platform-express';
import { Body } from '@nestjs/common';
import { JobsService } from './jobs.service';
import { createHash } from 'crypto';

@Controller('jobs')
export class JobsController {
  constructor(private readonly jobsService: JobsService) {}

  @Post()
  @UseInterceptors(FileInterceptor('file'))
  async submit(
    @UploadedFile() file: Express.Multer.File | undefined,
    @Body('areaPath') areaPath: string | undefined,
    @Body('customerId') customerId: string | undefined,
  ): Promise<{ jobId: string }> {
    if (!file) {
      throw new BadRequestException('file is required');
    }
    if (!areaPath) {
      throw new BadRequestException('areaPath is required');
    }
    const sourceHash = createHash('sha256').update(file.buffer).digest('hex');
    return this.jobsService.submit({
      // NOTE: userId is hardcoded as a placeholder here because the
      // req2ado session-JWT auth guard (SessionService, built in the
      // auth-corrections round) is not yet wired as an @UseGuards() on
      // this or any non-/auth route — a documented, pre-existing gap from
      // that round, not introduced by this task. Replace with the
      // authenticated request's userId once that guard is applied.
      userId: 'placeholder-user-id',
      areaPath,
      customerId: customerId ?? null,
      fileBuffer: file.buffer,
      filename: file.originalname,
      sourceHash,
    });
  }

  @Get(':id')
  async getById(@Param('id') id: string): Promise<{ id: string; status: string; dryRunDiff: unknown }> {
    const job = await this.jobsService.getById(id);
    if (!job) {
      throw new NotFoundException(`Job ${id} not found`);
    }
    return job;
  }

  @Post(':id/confirm')
  async confirm(@Param('id') id: string): Promise<{ status: string; createdCount: number }> {
    return this.jobsService.confirm(id);
  }
}
```

```tsx
// frontend/src/pages/Upload.tsx
import { useState, type JSX } from 'react';
import { Box, Button, FormControlLabel, Radio, RadioGroup, TextField, Typography } from '@mui/material';
import { httpClient } from '../api/httpClient.js';

export interface UploadProps {
  onJobSubmitted: (jobId: string) => void;
}

export function Upload({ onJobSubmitted }: UploadProps): JSX.Element {
  const [file, setFile] = useState<File | null>(null);
  const [areaPath, setAreaPath] = useState('');
  const [status, setStatus] = useState<'idle' | 'submitting' | 'error'>('idle');

  const handleSubmit = async (): Promise<void> => {
    if (!file || !areaPath) return;
    setStatus('submitting');
    try {
      const form = new FormData();
      form.append('file', file);
      form.append('areaPath', areaPath);
      const response = await httpClient.post('/jobs', form, { headers: { 'Content-Type': 'multipart/form-data' } });
      onJobSubmitted(response.data.jobId);
    } catch {
      setStatus('error');
    }
  };

  return (
    <Box sx={{ maxWidth: 480, mx: 'auto', mt: 8 }}>
      <Typography variant="h5" gutterBottom>
        Upload a Requirements Document
      </Typography>
      <RadioGroup value="baseline" sx={{ mb: 2 }}>
        <FormControlLabel value="baseline" control={<Radio />} label="Baseline (verbatim, deterministic)" />
        <FormControlLabel value="survey" control={<Radio />} label="Survey (coming soon)" disabled />
      </RadioGroup>
      <TextField
        fullWidth
        label="Area Path"
        value={areaPath}
        onChange={(event) => setAreaPath(event.target.value)}
        sx={{ mb: 2 }}
      />
      <Box sx={{ mb: 2 }}>
        <label htmlFor="file-input">File</label>
        <input
          id="file-input"
          type="file"
          aria-label="file"
          onChange={(event) => setFile(event.target.files?.[0] ?? null)}
        />
      </Box>
      <Button variant="contained" onClick={handleSubmit} disabled={!file || !areaPath || status === 'submitting'}>
        Upload
      </Button>
      {status === 'error' && <Typography color="error">Upload failed. Please try again.</Typography>}
    </Box>
  );
}
```

```tsx
// frontend/src/pages/JobStatus.tsx
import { useEffect, useState, type JSX } from 'react';
import { Box, Button, Table, TableBody, TableCell, TableHead, TableRow, Typography } from '@mui/material';
import { httpClient } from '../api/httpClient.js';

interface DryRunDiffEntry {
  localId: string;
  action: 'create' | 'reuse';
  existingAdoId: number | null;
}

interface JobData {
  id: string;
  status: string;
  dryRunDiff: DryRunDiffEntry[] | null;
}

export interface JobStatusProps {
  jobId: string;
}

export function JobStatus({ jobId }: JobStatusProps): JSX.Element {
  const [job, setJob] = useState<JobData | null>(null);
  const [confirmResult, setConfirmResult] = useState<{ createdCount: number } | null>(null);

  useEffect(() => {
    let cancelled = false;
    const poll = async (): Promise<void> => {
      const response = await httpClient.get(`/jobs/${jobId}`);
      if (!cancelled) setJob(response.data);
    };
    void poll();
    const interval = setInterval(() => {
      if (job?.status === 'pending' || job?.status === 'running' || job === null) {
        void poll();
      }
    }, 2000);
    return () => {
      cancelled = true;
      clearInterval(interval);
    };
  }, [jobId, job?.status]);

  const handleConfirm = async (): Promise<void> => {
    const response = await httpClient.post(`/jobs/${jobId}/confirm`);
    setConfirmResult({ createdCount: response.data.createdCount });
  };

  if (!job || job.status === 'pending' || job.status === 'running') {
    return <Typography>Processing…</Typography>;
  }

  return (
    <Box sx={{ maxWidth: 640, mx: 'auto', mt: 8 }}>
      <Typography variant="h5" gutterBottom>
        Job {job.id}
      </Typography>
      {job.dryRunDiff && (
        <Table>
          <TableHead>
            <TableRow>
              <TableCell>Node</TableCell>
              <TableCell>Action</TableCell>
            </TableRow>
          </TableHead>
          <TableBody>
            {job.dryRunDiff.map((entry) => (
              <TableRow key={entry.localId}>
                <TableCell>{entry.localId}</TableCell>
                <TableCell>{entry.action}</TableCell>
              </TableRow>
            ))}
          </TableBody>
        </Table>
      )}
      {job.status === 'diff_ready' && !confirmResult && (
        <Button variant="contained" onClick={handleConfirm} sx={{ mt: 2 }}>
          Confirm Write
        </Button>
      )}
      {confirmResult && <Typography sx={{ mt: 2 }}>{confirmResult.createdCount} item(s) written to ADO.</Typography>}
    </Box>
  );
}
```
