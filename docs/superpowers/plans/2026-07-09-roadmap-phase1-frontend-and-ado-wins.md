# Roadmap Phase 1 — Frontend Rebuild + Cheap ADO Wins Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship roadmap Phase 1 — 6 additive backend capabilities (jobs list, pre-parse preview, real ADO area-path picker, SSE stage progress, taxonomy-tag writeback, configurable State/Iteration) plus a greenfield frontend rebuild (react-router-dom + Zustand + MUI 6, Deep Indigo Enterprise visual language) — over the existing, ungrounded SURVEY/BASELINE pipeline.

**Architecture:** Backend tasks land first (each is additive, testable in isolation against the existing NestJS orchestrator / Express+MCP `mcp-ado-server` / FastAPI ingestion services). Frontend is a full greenfield replacement of `frontend/src/` built against the now-complete backend surface. SSE progress requires cross-process signaling (Redis pub/sub) because stage-progress writes happen in the `pipeline-worker` container while SSE clients connect to the `orchestrator` container — confirmed via `docker-compose.yml`, these are separate containers, not an in-process split.

**Tech Stack:** NestJS (orchestrator, Jest `.spec.ts`), Express + `@modelcontextprotocol/sdk` (mcp-ado-server, Vitest `.test.ts`), FastAPI (ingestion, unchanged this phase), Prisma/Postgres, BullMQ/Redis (`ioredis` transitively available via BullMQ), React 19 + Vite + MUI 6 + react-router-dom + Zustand (frontend, Vitest + `@testing-library/react`).

## Global Constraints

- All 6 backend additions are additive — no removal or breaking change of existing routes/behavior/signatures.
- PAT/org-URL travel only as per-request headers (`X-Ado-Org-Url` / `X-Ado-Pat`), never persisted server-side. Reuse `AdoRequestCredential` (`orchestrator/src/modules/pipeline/mcp.client.ts:10-13`) as the shared type instead of re-declaring the 2-field shape a 4th time.
- Frontend: PAT lives in `sessionStorage` only, mirrored from a Zustand `authStore`; never `localStorage`.
- Frontend API base URL comes from a runtime-fetched `/config.json`, not a Vite build-time `VITE_API_BASE_URL` (drop that build arg's role as the sole mechanism — keep it only as a fallback default baked into `config.json` if convenient, per `docker-compose.yml`'s existing `VITE_API_BASE_URL` build arg).
- Theme: extend `frontend/src/theme/tokens.ts`'s existing `themeTokens` object (navy `#0F1B3D` rail, existing `#1B458F` primary retained, cyan `#06B6D4` accent) — do not replace the token-object structure or introduce a second theme file.
- Docker Compose service names, ports, and volumes (`frontend:4082→80`, `orchestrator:3001`, `mcp-ado-server:4100`, `ingestion(→8010:8000)`, `postgres:5434→5432`, `redis:6381→6379`) stay unchanged.
- Test conventions: orchestrator = Jest, `*.spec.ts`, hand-built plain-object mocks passed positionally to constructors (see `orchestrator/test/jobs.service.spec.ts`) — no NestJS `TestingModule` bootstrap. mcp-ado-server = Vitest, `*.test.ts`, real `McpServer` + `MockAdoBackend(':memory:')`. frontend = Vitest + `@testing-library/react`, `vi.mock('../api/httpClient')` pattern (see `frontend/src/pages/JobStatus.test.tsx`).
- Keep `frontend/tsconfig.json`'s `"exclude": ["src/**/*.test.ts", "src/**/*.test.tsx"]` intact in the rebuilt scaffold — `tsc -b` must not choke on Vitest globals.
- Do not bake the Cato Networks CA-trust fix (`.certs/cato-ca-bundle.pem`, `NODE_EXTRA_CA_CERTS`) into any new product code path — it's dev-machine-only and already wired in `docker-compose.yml`.
- Quality scoring, RAG/SharePoint, editable diff, AI chat, trace/coverage links beyond parent-child are explicitly out of scope (Phase 2-4).

```ts
export interface JobSummary {
  id: string;
  mode: string;
  status: string;
  areaPath: string;
  itemCount: number;
  createdAt: Date;

async list(): Promise<JobSummary[]> {
  const rows = await this.prisma.job.findMany({
    orderBy: { createdAt: 'desc' },
    select: { id: true, mode: true, status: true, areaPath: true, dryRunDiff: true, createdAt: true },
  });
  return rows.map((row) => ({
    id: row.id,
    mode: row.mode,
    status: row.status,
    areaPath: row.areaPath,
    itemCount: Array.isArray(row.dryRunDiff) ? row.dryRunDiff.length : 0,
    createdAt: row.createdAt,
  }));
}
```

```ts
@Post('preview')
@UseInterceptors(FileInterceptor('file', { limits: { fileSize: MULTER_SAFETY_CEILING_BYTES } }))
async preview(@UploadedFile() file: Express.Multer.File | undefined): Promise<{ blockCount: number; sectionCount: number; fileType: string }> {
  if (!file) {
    throw new BadRequestException('file is required');

  return {
    blockCount: doc.blocks?.length ?? 0,
    sectionCount: doc.sections?.length ?? 0,
    fileType: ext,
```

Create `orchestrator/src/modules/pipeline/job-events.controller.ts`:

```ts
import { Controller, Get, Param, Res } from '@nestjs/common';
import type { Response } from 'express';
import type Redis from 'ioredis';

@Controller('jobs')
export class JobEventsController {
  constructor(private readonly redisSubscriberFactory: () => Redis) {}

  @Get(':id/events')
  async streamEvents(@Param('id') id: string, @Res() res: Response): Promise<void> {
    res.setHeader('Content-Type', 'text/event-stream');
    res.setHeader('Cache-Control', 'no-cache');
    res.setHeader('Connection', 'keep-alive');
    res.flushHeaders();

    const subscriber = this.redisSubscriberFactory();
    await subscriber.subscribe(`job-events:${id}`);

    const terminalStages = new Set(['diff_ready', 'failed']);
    subscriber.on('message', (_channel: string, message: string) => {
      const payload = JSON.parse(message) as { stage: string };
      res.write(`event: stage\ndata: ${JSON.stringify(payload)}\n\n`);
      if (terminalStages.has(payload.stage)) {
        void subscriber.unsubscribe();
        void subscriber.quit();
        res.end();
      }
    });

    res.on('close', () => {
      void subscriber.unsubscribe();
      void subscriber.quit();
    });
  }
}
```

Use a factory (`() => Redis`) rather than a shared singleton client because `ioredis` requires a dedicated connection per subscriber once `.subscribe()` is called (a subscribed connection can't issue other commands) — construct a fresh `new Redis(redisUrl)` per SSE connection via this factory, provided as a NestJS provider token (e.g. `'REDIS_SUBSCRIBER_FACTORY'`) in `pipeline.module.ts`, built from the same `redisUrl` already used to construct the BullMQ `Queue` in `jobs.service.ts`.

```ts
import { create } from 'zustand';

const STORAGE_KEY = 'req2ado-auth';

interface AuthState {
  orgUrl: string | null;
  pat: string | null;
  displayName: string | null;
  login: (orgUrl: string, pat: string, displayName: string) => void;
  logout: () => void;
}

function loadFromSessionStorage(): Pick<AuthState, 'orgUrl' | 'pat' | 'displayName'> {
  const raw = sessionStorage.getItem(STORAGE_KEY);
  if (!raw) return { orgUrl: null, pat: null, displayName: null };
  return JSON.parse(raw) as { orgUrl: string; pat: string; displayName: string };
}

export const useAuthStore = create<AuthState>((set) => ({
  ...loadFromSessionStorage(),
  login: (orgUrl, pat, displayName) => {
    sessionStorage.setItem(STORAGE_KEY, JSON.stringify({ orgUrl, pat, displayName }));
    set({ orgUrl, pat, displayName });
  },
  logout: () => {
    sessionStorage.removeItem(STORAGE_KEY);
    set({ orgUrl: null, pat: null, displayName: null });
  },
}));

export const useOrgUrl = (): string | null => useAuthStore((state) => state.orgUrl);
export const usePat = (): string | null => useAuthStore((state) => state.pat);
export const useDisplayName = (): string | null => useAuthStore((state) => state.displayName);
export const useIsAuthenticated = (): boolean => useAuthStore((state) => state.orgUrl !== null && state.pat !== null);
```

```ts
const SURVEY_MIN_MINUTES = 15;
const SURVEY_MAX_MINUTES = 40;
const SURVEY_MINUTES_PER_BLOCK = 0.5;
const BASELINE_FLAT_MINUTES = 1;

export function computeEtaMinutes(blockCount: number, mode: 'baseline' | 'survey'): number {
  if (mode === 'baseline') {
    return BASELINE_FLAT_MINUTES;
  }
  const estimate = SURVEY_MIN_MINUTES + blockCount * SURVEY_MINUTES_PER_BLOCK;
  return Math.min(SURVEY_MAX_MINUTES, Math.max(SURVEY_MIN_MINUTES, estimate));
}
```

```tsx
import { useMemo } from 'react';
import { FixedSizeList } from 'react-window';
import ListItemButton from '@mui/material/ListItemButton';
import ListItemText from '@mui/material/ListItemText';
import { ActionBadge } from './ActionBadge';
import { TagChips } from './TagChips';

export interface DryRunDiffEntry {
  localId: string;
  parentLocalId: string | null;
  type: string;
  title: string;
  description: string;
  action: 'CREATE' | 'REUSE' | 'SKIP';
  reuseId?: number;
  customerId: string | null;
  tags: string[];
}

interface FlatRow {
  entry: DryRunDiffEntry;
  depth: number;
}

function buildFlatRows(entries: DryRunDiffEntry[]): FlatRow[] {
  const byParent = new Map<string | null, DryRunDiffEntry[]>();
  const idSet = new Set(entries.map((entry) => entry.localId));
  for (const entry of entries) {
    const parentKey = entry.parentLocalId && idSet.has(entry.parentLocalId) ? entry.parentLocalId : null;
    const siblings = byParent.get(parentKey) ?? [];
    siblings.push(entry);
    byParent.set(parentKey, siblings);
  }
  const rows: FlatRow[] = [];
  function visit(parentKey: string | null, depth: number): void {
    for (const entry of byParent.get(parentKey) ?? []) {
      rows.push({ entry, depth });
      visit(entry.localId, depth + 1);
    }
  }
  visit(null, 0);
  return rows;
}

export function DiffTree({
  entries,
  selectedId,
  onSelect,
  filterAction,
  filterText,
}: {
  entries: DryRunDiffEntry[];
  selectedId: string | null;
  onSelect: (localId: string) => void;
  filterAction: string | null;
  filterText: string;
}): React.ReactElement {
  const rows = useMemo(() => {
    const allRows = buildFlatRows(entries);
    return allRows.filter((row) => {
      const matchesAction = !filterAction || row.entry.action === filterAction;
      const matchesText = !filterText || row.entry.title.toLowerCase().includes(filterText.toLowerCase());
      return matchesAction && matchesText;
    });
  }, [entries, filterAction, filterText]);

  return (
    <FixedSizeList height={600} width="100%" itemCount={rows.length} itemSize={56}>
      {({ index, style }) => {
        const row = rows[index];
        return (
          <ListItemButton
            key={row.entry.localId}
            style={{ ...style, paddingLeft: row.depth * 16 + 16 }}
            selected={row.entry.localId === selectedId}
            onClick={() => onSelect(row.entry.localId)}
          >
            <ActionBadge action={row.entry.action} reuseId={row.entry.reuseId} />
            <ListItemText primary={row.entry.title} secondary={<TagChips tags={row.entry.tags} />} />
          </ListItemButton>
        );
      }}
    </FixedSizeList>
  );
}
```

```tsx
import { useEffect, useState } from 'react';

function formatElapsed(ms: number): string {
  const totalSeconds = Math.floor(ms / 1000);
  const hours = Math.floor(totalSeconds / 3600);
  const minutes = Math.floor((totalSeconds % 3600) / 60);
  const seconds = totalSeconds % 60;
  const pad = (n: number): string => n.toString().padStart(2, '0');
  return hours > 0 ? `${hours}:${pad(minutes)}:${pad(seconds)}` : `${pad(minutes)}:${pad(seconds)}`;
}

export function ElapsedTimer({ startedAt }: { startedAt: string }): React.ReactElement {
  const [now, setNow] = useState(() => Date.now());

  useEffect(() => {
    const intervalId = setInterval(() => setNow(Date.now()), 1000);
    return () => clearInterval(intervalId);
  }, []);

  return <span>{formatElapsed(now - new Date(startedAt).getTime())}</span>;
}
```

```tsx
      <Box display="flex" justifyContent="space-between" alignItems="center" p={2}>
        {status && <StatusChip status={status} />}
        <Button variant="contained" disabled={status !== 'diff_ready'} onClick={handleConfirm}>
          Confirm
        </Button>
      </Box>
      {status === 'running' && stage && <ProgressBanner stage={stage} startedAt={startedAt} mode="survey" />}
      <Tabs value={tab} onChange={(_event, value) => (value === 'audit' ? handleShowAudit() : setTab(value))}>
        <Tab value="tree" label="Diff" />
        <Tab value="audit" label="Audit" />
      </Tabs>
      {tab === 'tree' ? (
        <Grid container>
          <Grid item xs={7}>
            <DiffTree entries={diff} selectedId={selectedId} onSelect={setSelectedId} filterAction={null} filterText="" />
          </Grid>
          <Grid item xs={5}>
            <NodeDetailPanel entry={diff.find((entry) => entry.localId === selectedId) ?? null} />
          </Grid>
        </Grid>
      ) : (
        <Box p={2}>
          {audit.map((entry) => (
            <Typography key={entry.id}>{entry.message}</Typography>

        </Box>

}
```

```tsx
import { Component, type ReactNode } from 'react';
import Box from '@mui/material/Box';
import Typography from '@mui/material/Typography';

interface State {
  hasError: boolean;
}

export class ErrorBoundary extends Component<{ children: ReactNode }, State> {
  state: State = { hasError: false };

  static getDerivedStateFromError(): State {
    return { hasError: true };
  }

  render(): ReactNode {
    if (this.state.hasError) {
      return (
        <Box p={4}>
          <Typography variant="h5">Something went wrong.</Typography>
          <Typography>Reload the page to continue.</Typography>
        </Box>
      );
    }
    return this.props.children;
  }
}
```

```tsx
import { createContext, useCallback, useContext, useState, type ReactNode } from 'react';
import Snackbar from '@mui/material/Snackbar';
import Alert from '@mui/material/Alert';

type Severity = 'error' | 'info' | 'success';

interface ToastContextValue {
  showToast: (message: string, severity: Severity) => void;
}

const ToastContext = createContext<ToastContextValue | null>(null);

export function ToastProvider({ children }: { children: ReactNode }): React.ReactElement {
  const [toast, setToast] = useState<{ message: string; severity: Severity } | null>(null);

  const showToast = useCallback((message: string, severity: Severity) => {
    setToast({ message, severity });
  }, []);

  return (
    <ToastContext.Provider value={{ showToast }}>
      {children}
      <Snackbar open={toast !== null} autoHideDuration={5000} onClose={() => setToast(null)}>
        {toast && <Alert severity={toast.severity}>{toast.message}</Alert>}
      </Snackbar>
    </ToastContext.Provider>
  );
}

export function useToast(): ToastContextValue {
  const context = useContext(ToastContext);
  if (!context) throw new Error('useToast must be used within a ToastProvider');
  return context;
}
```
